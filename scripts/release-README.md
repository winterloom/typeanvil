Typeanvil — AI-first HTML and Markdown to PDF typesetting engine

This archive contains the standalone `typeanvil` binary for your platform.

Quick start:

    ./typeanvil --help
    ./typeanvil render input.html --page-width 8.5in --page-height 11in -o output.pdf
    ./typeanvil render input.md --page-width 8.5in --page-height 11in -o output.pdf

Copy `typeanvil` onto your PATH to use it from anywhere. Install options,
fonts, and the MCP server setup are in the repository README.
